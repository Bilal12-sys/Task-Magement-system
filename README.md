# Task-Magement-system

## Project Structure

- `server.js` — Configures the Express app, API routes, middleware, and server startup.
- `routes/` — Defines task and AI API endpoints.
- `controllers/` — Handles incoming requests and sends responses.
- `services/` — Contains task and AI business logic.
- `models/` — Defines the MongoDB task model.
- `validators/` — Validates API request data.
- `middleware/` — Provides request validation and error handling.
- `config/` — Configures the database connection.
- `constants/` — Stores shared values such as HTTP status codes.
- `test/` — Contains API tests.
