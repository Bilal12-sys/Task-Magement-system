# Task Management System — Frontend

This directory contains the React and Vite frontend for the Task Management
System. It provides the dashboard, task management views, AI planner, and shared
UI components.

For the full project overview, setup instructions, API reference, and project
structure, see the [repository README](../README.md).

To run the frontend, configure `VITE_API_URL` in `.env` to point to the backend
API, then run these commands from this directory:

```sh
npm install
npm run dev
```
